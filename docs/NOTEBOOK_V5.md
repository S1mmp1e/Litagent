# 笔记库与个人模板

## 使用

1. 在“论文阅读”中选择论文和阅读模式，再选择“笔记模板”。
2. 模板下拉框旁的管理按钮可打开“个人笔记模板”。内置“论文精读”和“复现分析”两版初始模板。
3. “新建模板”清空名称、用途、正文、结构预览和历史版本选择。可以从空白开始设计，也可选中内置模板后“另存为个人模板”以沿用已有框架；未保存的编辑会先确认是否放弃。
4. “插入动态字段”按论文信息、阅读档案、本次阅读分组，提供 20 个字段。插入内容会选中并提示结果，预览使用当前选中论文和已保存阅读档案。
5. 保存并选择“用于本次阅读”，再提交阅读任务。任务保存模板 ID、版本及完整内容快照。
6. 成功生成的结果自动出现在“我的笔记”。也可从文献库每篇论文的笔记数量进入。
7. 笔记支持标题修改、正文搜索、分类/模式筛选、收藏、版本编辑、回收站恢复。
8. 点击正文引用，在对照区域查看保存的原文片段和对应 PDF 页。窄屏使用“笔记 / PDF 原文”切换。
9. 下载图标导出当前选中的笔记版本；阅读包包含 Markdown、原始 PDF、引用说明及模板快照。

## 存储与行为

- `notes` 继续保存正文版本，已有记录不会改写；`notebooks` 保存标题、收藏、回收站状态与更新时间。
- `note_sources` 保存每个任务实际使用的 PDF 哈希及论文关联；比较笔记关联多篇论文，正文只保存一份。
- `note_evidence` 保存引用片段快照，避免重新解析后历史证据变化。
- 历史笔记通过迁移接入笔记库。若原文在升级前已经丢失，迁移不会伪造原文或证据。
- 论文从文献库删除后，已被笔记引用的 PDF 保留。原文依然可从笔记中打开，不再参与文献库检索。
- 回收站针对笔记提供可恢复的归档；首版不提供永久清空笔记和关联原文。
- 备份脚本同时包含仅被笔记引用的 PDF；不能只复制正在运行中的 SQLite 主文件。
- 个人模板按版本追加保存。内置模板保留；删除个人模板不会改变已提交任务或旧笔记的模板快照。
- 新模板只显示草稿状态；至少保存两个版本后显示“版本历史”。可以查看旧版内容，再保存为新版本；取消切换会保留原稿和对应的版本选择。
- 新建模板会重置正文选区、滚动位置及插入提示；之前的加载或保存请求即使稍后完成，也不会覆盖新草稿。
- 动态字段目录、预览取值和任务生成使用同一套服务端定义。任务提交时冻结字段值，重试不会读取之后修改的论文元数据或档案；笔记日期采用服务端本地的任务提交日期。
- 多篇论文的作者、年份等元数据按选择顺序标为论文 A / B；缺失元数据显示“未提供”，档案缺项显示“未设置”，没有选择论文时显示“未选择论文”。这些字段不生成或推测研究结论。
- 字段仅作一次文字替换，不执行模板代码，不展开元数据里嵌套的占位符。未注册的占位符保留原样。
- Skill 负责分析流程，模板负责输出结构。模板相关需求进入全文分段提取和最终生成；证据约束始终保留。
- 切换模板会开启新的阅读上下文。不同模板的分段材料缓存独立计算，避免复用遗漏模板关注项的材料。
- 模板二级标题匹配只用于提示结构缺失，不代表内容质量、证据充分性或模型能力提升。
- 修改笔记与同意纳入训练样本是独立操作；本功能不进行 SFT，也不自动授权导出全部笔记。

## 动态字段

| 分组 | 字段 |
|---|---|
| 论文信息 | `paper_title` 标题、`paper_authors` 作者、`paper_year` 年份、`paper_venue` 期刊或会议、`paper_doi` DOI、`paper_arxiv_id` arXiv 编号、`paper_pdf_url` PDF 来源链接、`paper_abstract` 摘要 |
| 阅读档案 | `reading_purpose` 阅读目的、`reading_focus` 关注内容、`knowledge_background` 知识背景、`research_domain` 研究方向、`known_topics` 已掌握知识、`reading_depth` 讲解深度、`output_language` 输出语言、`preferred_framework` 框架、`compute_budget` 可用算力 |
| 本次阅读 | `note_date` 笔记日期、`reading_mode` 阅读模式、`paper_count` 论文数量 |

模板中使用 `{{字段名}}`。例如 `作者：{{paper_authors}}`、`关注点：{{reading_focus}}`。
