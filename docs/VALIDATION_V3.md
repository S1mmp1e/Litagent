# LitAgent v3 验收记录

日期：2026-11-13。本文区分代码实现、离线验证和实际在线效果，不将三者混用。

本文件保留 11 月 13 日的历史验收状态。11 月 15 日的模型就绪情况、数据量和新增功能验证记录见 `VALIDATION_V4.md`，使用说明见 `READING_V4.md`。

## 已实现

- 本地 PDF 上传、固定 arXiv 来源下载、哈希复用、逐页解析、分块来源定位。
- E5 tokenizer 分块、Qdrant 本地向量接口、SQLite FTS5、RRF 融合和版本过滤。
- 全文逐段阅读及持久化阶段笔记；指定论文范围的证据追问。
- 版本化概览/精读/对比 Skills、阅读档案快照。
- 单工作线程、持久化任务与事件、SSE、取消、只读任务恢复/重试。
- 文献管理对话服务端上下文、参数验证及 12 轮调用上限；中断的写操作不自动重放。
- 引用 ID 校验和 PDF 页码跳转；笔记版本、人工审核、审核样本导出。
- 本地环境变量密钥管理、已分发文本/Word 密钥脱敏、Docker/Compose 配置。

## 首版边界与后续验收

- Windows 下不要复用固定的 `--basetemp=.pytest-tmp`：Codex 沙箱与普通终端创建目录的权限可能不同，导致所有使用 `tmp_path` 的测试在 setup 阶段失败。测试配置已改用 pytest 默认临时目录，并禁用跨账号共享的项目测试缓存；旧 `.pytest-tmp` 和 `.pytest_cache` 无须删除。在沙箱外以普通用户权限复测通过。沙箱内如无权访问普通用户的系统临时目录，应申请沙箱外测试权限，不要修改该目录的访问权限。

- 系统适合单用户本机演示，不具备公网产品的身份认证、配额管理和数据隔离。
- pypdf 不负责 OCR，双栏、表格、公式的提取质量仍需人工检查。
- SQLite FTS5 默认分词对连续中文的词语召回有限；跨语言语义检索依赖真实 E5 编码器。
- 任务时限是协作式检查：HTTP 调用有超时，但单次本地 PDF 解析/模型编码不能在执行中被强制抢占。
- 资料中包含恶意指令的场景目前靠权限隔离和提示约束，尚未做系统化攻击评测。
- 完成新密钥与模型初始化后，先做一篇真实论文的上传、索引、全文总结、追问和引用核对，再执行公平的真实评测。用实测值更新简历，不用示例数值。
