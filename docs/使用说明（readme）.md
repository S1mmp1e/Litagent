# LitAgent 使用说明

完整操作见 [用户手册](USER_GUIDE.md)，安装和首次运行见 [项目 README](../README.md)。

推荐顺序：

1. 安装依赖、配置服务端密钥并准备本地嵌入模型。
2. 导入文字型 PDF，完成全文处理。
3. 选择论文、阅读模式和模板，生成笔记并核对引用。
4. 在“我的笔记”管理结果，在 PDF 中添加个人批注。
5. 明确选择要复用的笔记版本或批注，再开启个人材料问答。

启动入口为 `python -m scripts.launch` 或 Windows 的 `start_webui.bat`。启动器检查现有环境，不自动安装依赖。模型密钥保存在服务端 `.env` 或环境变量中。

故障处理、数据位置和备份见 [部署指南](DEPLOYMENT.md)；功能示例见 [演示画面](SHOWCASE.md)。
