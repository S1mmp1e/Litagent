# LitAgent 使用说明

完整操作见 [用户手册](USER_GUIDE.md)，安装和首次运行见 [项目 README](../README.md)。

推荐顺序：

1. 安装依赖并准备本地嵌入模型，然后启动服务。
2. 打开 `http://127.0.0.1:7860`，点击右上角“模型设置”，填写 API 地址、模型名称和自己的 API Key，测试连接后保存。
3. 导入文字型 PDF，完成全文处理。
4. 选择论文、阅读模式和模板，生成笔记并核对引用。
5. 在“我的笔记”管理结果，在 PDF 中添加个人批注。
6. 明确选择要复用的笔记版本或批注，再开启个人材料问答。

启动入口为 `python -m scripts.launch` 或 Windows 的 `start_webui.bat`。启动器检查现有环境，不自动安装依赖。

页面保存后新任务使用新配置，不需要重启；连接测试只查模型列表，不发送论文、不自动保存。页面配置保存在本机 `LIT_DATA_DIR/model-config.json`（默认 `data/model-config.json`），含明文密钥，不应上传或分享。也可使用服务端 `.env` 或环境变量，页面配置优先；点击“恢复环境配置”移除页面覆盖，不改写 `.env`。完整说明见 [首次配置 API](USER_GUIDE.md#首次配置-api)。

故障处理、数据位置和备份见 [部署指南](DEPLOYMENT.md)；功能示例见 [演示画面](SHOWCASE.md)。
