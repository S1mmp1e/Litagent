# LitAgent 产品需求与范围

## 使用者与目标

面向反复阅读、追问和积累研究笔记的个人研究者。根据原文解释论文、保留可核查来源，让研究背景与经过选择的个人理解参与后续阅读。

当前范围是本机单用户、单服务进程。团队协作、账号权限、公网部署和大规模分布式任务不属于当前交付能力。

## 主要使用路径

| 阶段 | 用户需要 | 当前能力与验收条件 |
|---|---|---|
| 收集 | 导入与组织论文 | arXiv、本地 PDF、分类与标签；保留既有文献 |
| 理解 | 获得完整解释 | 全文分段处理与合成；明确提取限制 |
| 追问 | 找到具体依据 | FTS5 与向量混合检索；引用定位片段和页码 |
| 个性化 | 适配阅读需求 | 档案、8 个 Skills、版本化模板与动态字段 |
| 沉淀 | 长期保存成果 | 笔记库、版本、收藏、回收站、来源快照与导出 |
| 批注 | 记录局部理解 | PDF 高亮、评论、颜色、修订、定位与删除 |
| 复用 | 结合个人知识回答 | 明确选择的版本参与检索，两类来源分开 |
| 恢复 | 刷新和中断后继续 | 持久化任务与事件、检查点、取消与可重试步骤 |

## 交互与一致性

- 切换论文后同步切换 PDF、结果与笔记，过期请求不得覆盖当前选择。
- 两篇对比必须显式选择 A 和 B，保留各自来源身份。
- 新建模板清空旧正文与草稿状态，字段插入遵循当前光标位置。
- 新笔记正文必须重新选择用于个人问答，不默认沿用旧版选择。
- 删除、撤回、过期材料不得进入新回答；旧答案保留生成时的来源快照。
- 失败展示明确状态，半截输出不能保存为成功笔记。
- 桌面与手机不能横向遮挡主要控件，PDF 高亮随缩放对齐。

## 非功能要求

密钥只在服务端配置，日志不输出密钥与完整请求材料；论文和模板不能改变工具权限。迁移保留原有数据，备份包含数据库与 PDF、排除密钥。Markdown 经过清理，模型生成内容不能执行脚本。

正确率、检索命中与个性化效果需要人工审核集上的实测。SFT、OCR、复杂公式/表格识别、跨用户访问控制属于后续方向。
