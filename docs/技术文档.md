当前重点是全文阅读与混合检索、可版本化 Skills、个人笔记模板、PDF 批注和明确选择的个人材料问答。主流程使用服务端创建的 DeepSeek API 客户端，并提供显式的“模型设置”入口。

用户可在页面填写 API 地址、模型名称和密钥，测试连接后保存；密钥保存在本机数据目录，不回传、不写入浏览器存储。页面配置优先于环境配置，新建模型客户端使用保存后的值；恢复环境配置不修改 `.env`。实现见 [技术设计的模型配置说明](TECHNICAL_DESIGN.md#模型配置与调用入口)，接口与失败状态见 [API 参考](API_REFERENCE.md#模型配置接口)。启动器仍只检查依赖，不在每次启动时安装依赖。

早期 v3–v6 文档保留阶段性实现记录，其历史测试数量与界面描述不能代替当前文档。
