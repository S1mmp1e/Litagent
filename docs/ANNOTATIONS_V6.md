# PDF 批注与个人笔记问答

## 使用

1. 打开“论文阅读”“我的文献库”“分类浏览”或“我的笔记”中的 PDF。
2. 选择当前页的文字，点击选区工具栏中的“添加批注”，填写评论、选择颜色并保存。
3. 批注中的“用于后续问答”控制该条批注是否进入个人材料检索。高亮笔图标打开批注列表；可以定位原文、修改、删除以及查看历史版本。选择旧版本后保存会产生一个新版本。
4. 在“我的笔记”选中一篇笔记，勾选“将此版本用于后续问答”。此设置只适用于最新正文版本；保存新正文后需要重新勾选。默认不选择 AI 原稿。该设置不等于同意纳入训练数据。
5. 在“论文阅读”勾选“结合已选个人笔记与批注”，选择论文并开始全文总结或证据追问。例如：“结合我的批注，分析这个方法是否符合我的部署条件。”
6. 结果中的“原文”和“个人笔记”使用不同引用标记。点击个人引用查看生成时的材料版本；批注引用可以打开对应 PDF 页，笔记引用可以打开来源笔记。

## 数据与范围

- 新增迁移 4，仅新增表，既有文献、分类、笔记及任务不改写。
- `annotations` 保存当前批注；`annotation_versions` 保留评论、颜色及选择状态的历史版本。
- 位置绑定论文 ID、PDF SHA-256、页码和 PDF 坐标矩形；保存摘录及前后文。缩放后转换坐标重绘，同一文件重新索引仍能保留批注。
- 服务端校验文件归属、页码和矩形边界；对摘录做规范化文本匹配。匹配状态只说明文字可匹配，不能证明评论正确。匹配失败仍可保存，但显示“摘录未与解析原文匹配”，并将该状态提供给模型。
- 批注可在全文索引前创建；问答仍需论文完成全文处理。首版仅支持单页内的文字选区，不做 OCR、跨页选区、手写画笔或将批注写入 PDF 文件。
- `personal_notes` 记录用户明确选择的笔记版本。历史版本、回收站笔记、未选择的草稿不参与检索；多论文笔记只有在所有关联 PDF 都属于本次阅读范围时才参与，避免泄露其他论文内容。

## 检索与一致性

- 原文检索保持原有流程；个人材料另建 SQLite FTS5 表和 Qdrant `personal_e5_small_v1` 集合。
- 在启用个人材料的阅读任务中按需增量索引，沿用本地 E5 编码、350 token 分块和 40 token 重叠；采用 query/passage 前缀、BM25 与向量检索、RRF 融合。
- 每次最多提供 5 个个人片段，同一来源最多 2 个。个人材料有独立预算，不替换原文证据，也不被当作原文引用校验的输入。
- 读取当前版本和选择状态后检索，返回前再次检查；任务合成完成和事务保存前再校验。材料在生成期间修改、撤回或删除时，不保存使用过期材料的新答案。
- 修改、停用、删除后立即退出可见检索集合，物理旧索引在后续索引同步中清理。没有可用个人材料时不查询旧索引。
- 任务保存个人材料快照，旧答案继续展示历史来源，并标明来源已变化。删除批注不会修改已有回答或删除其历史快照。
- 生成中断后按文档、材料范围和版本重新校验缓存；切换个人材料开关或修改材料会隔离旧问答上下文。
- Markdown 导出将个人引用转换为独立脚注，包含生成时版本和摘录。自动核查仅评估原文证据；仅含个人引用的段落标为个人材料，不声称完成论文事实核查。
